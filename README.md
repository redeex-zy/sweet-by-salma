# Sweet by Salma

Website for **Sweet by Salma**, a custom cake and dessert studio in El Kelaa des Sraghna, Morocco.

**Preview:** https://redeex-zy.github.io/sweet-by-salma/

### About

A simple place to browse cake designs and request personalized creations. The site is available in French and Arabic, with mobile-friendly layouts and direct WhatsApp enquiries.

### Built with

HTML, CSS and vanilla JavaScript. No framework or build step required.

### Run locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 3000
```

Then visit http://localhost:3000.

### Updating the gallery

Cake listings are in the `cakes` array in `script.js`. Images live in `assets/cakes/`. Add a WebP image and its corresponding entry to publish a new design.

**Note:** Some gallery visuals are edited or illustrative studio renditions. Confirm designs and details with Sweet by Salma before placing an order.
